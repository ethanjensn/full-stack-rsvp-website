# Naming conventions

Keeping file names consistent makes the project easier to navigate.

## Python modules

Use `snake_case.py`.

- `app.py`
- `config.py`
- `test_rsvp.py`

## HTML templates

Use `kebab-case.html`.

- `admin-login.html`
- `submit-rsvp.html`
- `q-and-a.html`
- `rsvp.html`

## Static assets

Use `kebab-case` for CSS, images, and JS.

- `circle-flowers-4.png`
- `rsvp-hero.jpg`
- `style.css`

## SQL files

Use lowercase, descriptive names.

- `users.sql`

## Environment files

Name them after what they do. For local PowerShell env setup, prefer `set-env.ps1` or `env.ps1` instead of `sql.txt`.
